StockWise POS

StockWise POS is a browser-based Point of Sale (POS) and inventory management application developed for our Web Systems and Technologies course.

The application provides features for managing orders, inventory, customer rewards, reports, notifications, and system settings.

Milestone 1: Interactive Frontend Web Application

Milestone 1 focused on developing the application’s frontend using HTML, CSS, and JavaScript.

The application included interactive features such as order processing, inventory management, customer rewards, reports, form validation, notifications, and system settings.

Milestone 2: Backend-Supported Browser-Based Application

Milestone 2 focused on integrating backend technologies into the existing StockWise POS application.

The team implemented Node.js, Express.js, and EJS to support server-side rendering (SSR), application routing, and backend-supported features.

Implemented Features

* Node.js and Express.js backend server
* EJS server-side rendering
* Login and Dashboard page routing
* Orders and Complete Order page integration
* Inventory management page integration
* Reports and Sales Breakdown page integration
* Rewards, Notifications, and Settings page integration
* Backend-supported customer management
* Customer data persistence using JSON file storage
* Customer input validation
* Customer CRUD operations (Create, Read, Update, Delete)

Rewards Customer Management

The Rewards module was enhanced with backend-supported customer management.

Implemented operations include:

* Adding new customers
* Viewing customer information
* Editing customer information
* Removing customer records
* Saving and retrieving customer records through JSON file storage

Customer information is managed through the Express.js backend and stored in data/customers.json.
